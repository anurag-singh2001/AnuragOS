# PRODUCT_REQUIREMENTS.md

# Product Goal

Create an interactive portfolio called AnuragOS.

The experience should feel like navigating a software system.

---

# Primary Audience

1. Recruiters
2. Engineering Managers
3. Technical Interviewers
4. Fellow Engineers

---

# MVP Features

## Boot Sequence

Purpose:

Create a memorable first impression.

Requirements:

* Maximum 4 seconds
* Skippable
* Lightweight

---

## Dashboard

Purpose:

Serve as the central navigation hub.

Requirements:

* Quick overview
* Current focus
* Experience summary
* System status

---

## Deployments

Purpose:

Showcase engineering work.

Requirements:

* Project cards
* Architecture views
* Technology stack
* Challenges and solutions

Projects should be presented as systems, not assignments.

---

## Experience

Purpose:

Communicate professional growth.

Requirements:

* Timeline
* Responsibilities
* Impact

---

## AI Lab

Purpose:

Show current exploration.

Requirements:

* Claude Code
* AI Agents
* RAG
* MCP
* Experiments

---

## Terminal

Purpose:

Provide an interactive exploration method.

Commands:

help
about
experience
deployments
ai
resume
contact

---

## Recruiter Mode

Purpose:

Reduce exploration time.

Requirements:

One-click summary of:

* Experience
* Skills
* Projects
* Resume
* Contact

---

# Future Features

* AI Assistant
* Voice Interface
* Live GitHub Analytics
* Interactive System Maps

These should not block MVP development.
