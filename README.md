# AnuragOS

AnuragOS is a highly interactive, immersive web-based desktop environment serving as my personal developer portfolio. Built to simulate a modern, feature-rich operating system, it provides an engaging way to explore my career journey, skills, and projects as an Enterprise and AI Systems Builder.

![AnuragOS Desktop Preview](./public/favicon.ico)

## 🚀 Key Features

*   **Window Manager**: Draggable, resizable, and focusable application windows with smooth Framer Motion transitions.
*   **Dynamic Wallpapers**: Three fully interactive wallpapers: Matrix Digital Rain, Cyber Grid, and Deep Void.
*   **System Preferences**: A persistent settings app that saves configurations (wallpapers, colors, fast boot, etc.) to local storage.
*   **Interactive Terminal**: A fully functional command-line interface with custom commands (`quote`, `quiz`, `origin`, `now`) and a mini-game (`snake`).
*   **Guided Tour**: A "2-Minute Tour" onboarder that walks visitors through the core applications.
*   **Rich Applications**:
    *   **Career**: A detailed interactive timeline of my educational and professional journey.
    *   **Engineering Graph**: An overview of my technical stack and core competencies.
    *   **AI Lab**: Demonstrations of AI integrations and systems thinking.
    *   **Deployments**: Detailed case studies of enterprise and scalable systems I've built.
    *   **Resume & Contact**: Quick access to my professional documentation and links.

## 🛠️ Technology Stack

*   **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
*   **Library**: [React 19](https://react.dev/)
*   **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/)
*   **Language**: TypeScript

## 💻 Running Locally

To run AnuragOS locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/anurag-singh2001/AnuragOS.git
   cd AnuragOS
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.
